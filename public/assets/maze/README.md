# Background do Jogo do Labirinto

Para criar o background do jogo do labirinto, você pode:

1. **Copiar temporariamente o background do jogo de formas:**
   - Copie: `public/assets/forms/bg.png`
   - Para: `public/assets/maze/bg.png`

2. **Ou criar um novo background personalizado:**
   - Tamanho recomendado: 1248x832 pixels (mesma proporção do jogo de formas)
   - Tema: labirinto, aventura, exploração
   - Cores: pastéis suaves para crianças
   - Elementos: paredes de tijolos, plantas, decorações cartunescas

Por enquanto, o jogo funcionará com qualquer imagem neste caminho: `/assets/maze/bg.png`
